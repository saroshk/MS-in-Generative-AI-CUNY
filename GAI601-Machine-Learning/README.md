# Bank Marketing – End-to-End Machine Learning Project

Four-part machine learning project completed for **GAI 601 – Machine Learning**, M.S. in Generative AI, CUNY School of Professional Studies.

Uses the public **UCI Bank Marketing dataset** to predict whether a customer will subscribe to a term deposit, following the full ML lifecycle from business framing to responsible AI.

## Project Structure

| Assignment | Folder | What it covers |
|---|---|---|
| 01 | `assignment-01_business-goal` | Business context, goals, problem definition, stakeholders, success KPIs |
| 02 | `assignment-02_exploratory-data-analysis-eda` | Exploratory Data Analysis (EDA): data quality checks, cleaning, visual insights |
| 03 | `assignment-03_model-training` | Experimentation and comparison of three ML algorithms |
| 04 | `assignment-04_ethics-explainability` | Model explainability, fairness, and ethical considerations |
| — | `data` | `bank-additional-full.csv` (original UCI data, Assignment 02) and `bank_marketing_cleaned.csv` (cleaned output, Assignments 03–04) |

## Tools
Python, pandas, NumPy, scikit-learn, XGBoost, SHAP, Matplotlib/Seaborn, Jupyter / Google Colab

## Dataset
Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306

## How to Run
1. Clone this repo.
2. Open the notebooks in Jupyter or Google Colab.
3. Upload the matching CSV from `data/` to the same folder as the notebook (or to the Colab file panel), then run cells in order: Assignment 02 uses `bank-additional-full.csv`; Assignments 03–04 use `bank_marketing_cleaned.csv`.

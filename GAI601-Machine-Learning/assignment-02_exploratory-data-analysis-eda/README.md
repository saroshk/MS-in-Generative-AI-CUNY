Part 1: Assignment Instructions
Introduction
Exploratory Data Analysis (EDA) is one of the most important aspects of data science. Many surveys show that data scientists spend 60-80% of their time on data analysis, preparation and feature engineering. EDA is critical to understand the data, identify data issues, improve data quality, and create better features (feature engineering) - and that ultimately helps train better models. In machine learning, there is a saying - "better data beats better algorithms" - meaning that it is more productive to spend time improving data quality than improving the training the model on bad data.
